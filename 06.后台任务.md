## 运行逻辑

1. 只要当前后台任务有新的 output 信息或完成,即向 user 消息添加 part

- 已完成的任务

```md
<system-reminder>
Background Bash bash_1 (command: echo 123) (status: completed) (exit code: 0) Has new output available. You can check its output using the BashOutput tool.
</system-reminder>
```

- 正在运行的任务

```md
<system-reminder>
Background Bash bash_2 (command: ping baidu.com) (status: running) Has new output available. You can check its output using the BashOutput tool.
</system-reminder>
```

2. 每次使用`BashOutput`工具获取自上一次至今的控制台输出的信息
